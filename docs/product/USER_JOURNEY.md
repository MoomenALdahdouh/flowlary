# User journey

1. Install from Chrome Web Store (or load `extension/dist`).
2. First-run: what to help with (layout / English / Arabic→English). Maps to `UserWritingPolicy`.
3. Type on any site. Default: Flowlary on, no denylist.
4. Wrong keyboard: local remap after a completed token (auto or suggestion).
5. English island: local instant typos; after pause, Writing Review may propose spans.
6. Arabic→English: enable mode / session; completed sentences may translate; shortcut always available.
7. Pause globally or exclude one host from the popup.
8. Account (optional): website login, Pro via Paddle, credits on free.
9. Dashboard: history, practice, reports — learning does not hijack the writer.

Failure: if the API is down, **typing and local layout still work**. Review, translation, and non-instant CORRECT need the gateway.
