# Chrome Web Store — Full Description (draft)

**Flowlary** helps you write clearly across languages and keyboard layouts — without switching between multiple tools.

## Keyboard layout correction (always free)
Typed on the wrong keyboard layout? Flowlary detects common Arabic/English (and other layout) mistakes and fixes them locally. Use **Ctrl/Cmd+Shift+P** for Fix Layout, or open **Speed Box** with **Ctrl/Cmd+Shift+L** for layout, translate, and fix in one overlay.

## Writing correction
Improve English grammar and spelling with Flowlary AI. Sign in for a **30-day free trial** with **1,000 AI writing checks per day** (no credit card required). The **Free** plan includes **500 AI writing checks per day** plus unlimited local layout tools.

## Translation
Translate with **Ctrl/Cmd+Shift+,**. Optional **live translation** when Direct mode is on (off by default). Google translation routing does not use AI writing checks when Google routing is active.

## Learning
Dashboard includes daily brief, practice from your mistakes, progress, and learning report (Trial/Pro/Student Pro).

## Safety first
Flowlary skips password fields, payment fields, code editors, and other sensitive inputs. You can pause globally or exclude websites.

## Plans
- **Free** — 500 AI writing checks/day + local layout tools (Keyboard Layout Repair, Speed Box)
- **Trial** — 30 days full Pro experience on signup; no card required; then continues on Free
- **Pro** — $4.99/month or $39/year; 1,000 AI writing checks/day via [flowlary.com](https://flowlary.com)
- **Students** — 12 months of Pro after academic-email verification on flowlary.com (verification confirms email control, not enrollment status)

## Permissions
- **storage** — settings and learning data locally
- **activeTab** — shortcuts on the page you're typing in
- **clipboardWrite** — copy Speed Box results
- **Host access** — Flowlary API (`api.flowlary.com`) for AI features
