# Product overview

Flowlary is a **Chrome writing companion** for people who mix Arabic and English: wrong-keyboard repair, light English correction, and optional Arabic→English translation **in the field they are already typing in**.

It is **not** a separate editor, not a chatbot, and not a style rewriter.

## Surfaces

| Surface | Job |
| --- | --- |
| Extension (content) | Observe typing, decide, Write Gate |
| Popup | Pause, policy, site exception, first-run |
| Extension dashboard | History, practice, learning, settings |
| Website | Marketing, account, pricing, legal, support |
| Website Writing Lab | Demo using **gateway correction API**, not the live engine |
| API | Auth, entitlement, AI, billing, learning sync |

## Promise

Local layout and safety are **immediate**. Cloud review is **asynchronous** and optional. The user can always type, undo, and add a site exception.
